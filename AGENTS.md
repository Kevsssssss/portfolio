# AGENTS.md

This repository is a personal portfolio website for **John Kevin F. Buangjog**, built for a
school activity and published with GitHub Pages.

**All planning, content, design, deployment, and history documentation lives in [`AGENTS/`](./AGENTS/).**
Read `AGENTS/README.md` first — it indexes every file and states the rules for working here.

## Ground rules for any agent

1. **Read `AGENTS/README.md` and `AGENTS/PLAN.md` before making changes.**
2. **Never invent content.** Personal details, skills, and project facts come from `AGENTS/PROFILE.md`
   and `AGENTS/PROJECTS.md`. If a fact is missing, ask the user — do not guess.
3. **Keep the site dependency-free.** Plain HTML/CSS/JS, system fonts, no CDN or framework.
4. **Do not publish private material.** The deploy workflow stages only site files. `about_me.md`,
   `Website_Portfolio_Student_Guide.docx`, and `AGENTS/` must never end up in `_site/`.
5. **Update the docs with the code.** Any change to pages, design, or deployment must be reflected in
   `AGENTS/` and logged in `AGENTS/CHANGELOG.md` with the date and the AI tools used.
6. **Test before pushing.** Check desktop + narrow (phone) widths, every navigation link, and the
   `mailto:` link.
